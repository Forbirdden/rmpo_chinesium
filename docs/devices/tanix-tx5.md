## Прошивка

- Отключите все кабели от приставки

- Зажмите маленькую кнопку внутри AUX порта

- Подключите кабелем к компьютеру, кнопку можно отпустить

- В Amlogic USB Burning Tool выберите File >> Import Image и файл прошивки

- Нажмите Start
